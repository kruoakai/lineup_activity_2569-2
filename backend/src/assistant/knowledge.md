# ความรู้ของระบบเช็กชื่อเข้าแถว วิทยาลัยเทคนิคชัยภูมิ (สำหรับน้องแถวดี)

เว็บแอป: https://lineup.ccollege.ac.th ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ติดตั้งเป็นแอปบนมือถือได้
**คู่มือการใช้งาน (อ่านบนมือถือได้):** หน้าเข้าสู่ระบบ → ปุ่ม “📖 คู่มือการใช้งาน” หรือ ☰ เพิ่มเติม → คู่มือการใช้งาน (https://lineup.ccollege.ac.th/manuals) มีคู่มือแยกตามหน้าที่และดาวน์โหลด PDF ได้
เมนูล่างของแอป: ✓ เช็กชื่อ (หน้าแรก) · 🗓 ประวัติ · 👥 รายชื่อ (เฉพาะผู้มีสิทธิ์) · 📊 รายงาน (เฉพาะผู้มีสิทธิ์) · ☰ เพิ่มเติม

## บทบาทในระบบ
| บทบาท | ทำอะไรได้ |
| --- | --- |
| ครูและบุคลากร (staff) | เช็กชื่อของตนเอง ดูประวัติและสถิติของตนเอง แก้โปรไฟล์ บันทึกลายเซ็น |
| ตัวแทนเช็กชื่อแผนก | ทุกอย่างของครู + เช็กแทนเพื่อนในแผนก เช็กแบบกลุ่มพร้อมรูป |
| หัวหน้าแผนก (dept_head) | ดูรายชื่อและรายงานของแผนก เช็กแทนคนในแผนก |
| เจ้าหน้าที่งานกิจกรรม (activity) | แสดง QR อนุมัติคำขอ บันทึกไปราชการ/ลาแทน จัดปฏิทินวันเข้าแถว ดูรายงานทุกแผนก |
| เจ้าหน้าที่บุคลากร (hr) | งานบุคลากรประจำวัน: บันทึกลา/ราชการ/งานนโยบาย/มาสาย/ไม่ลงเวลากลับ/ประเภทบุคลากร เช็กชื่อแทนครูที่มือถือเสีย สร้างและแก้ไขรายงานสรุปการปฏิบัติงานประจำวัน |
| ผู้บริหาร / ผู้ลงนาม (executive) | ลงนามเอกสาร ดูรายงานและสารสนเทศ (ไม่แก้ข้อมูล) |
| ผู้ดูแลระบบ (admin) | ตั้งค่าทั้งหมด ผู้ใช้ ผู้ลงนาม สำรอง/กู้คืน ข้อมูลจำลอง อีเมล LINE |

## เริ่มต้นใช้งาน
- เข้าสู่ระบบด้วย **รหัสพนักงาน หรืออีเมล** + รหัสผ่าน ครั้งแรกใช้รหัสเริ่มต้นที่ผู้ดูแลแจ้ง แล้วระบบบังคับตั้งรหัสใหม่และยอมรับนโยบายข้อมูลส่วนบุคคล (PDPA)
- ช่องรหัสผ่านมีปุ่มรูปตา 👁 กดเพื่อดู/ซ่อนรหัส
- “จำฉันไว้ในระบบ” ติ๊กไว้ = ไม่ต้องเข้าระบบใหม่ทุกครั้ง ไม่ติ๊ก = ออกเมื่อปิดเบราว์เซอร์ (เหมาะเครื่องส่วนกลาง)
- **ลืมรหัสผ่าน:** หน้าเข้าสู่ระบบ → “ลืมรหัสผ่าน?” → ใส่รหัสพนักงานหรืออีเมล → รับลิงก์ทางอีเมล (ใช้ได้ครั้งเดียว) ถ้าไม่มีอีเมลในระบบหรือไม่ได้รับ ให้ติดต่อผู้ดูแลระบบให้รีเซ็ตให้
- ออกจากระบบ: ปุ่ม “ออก” มุมขวาบน
- **ติดตั้งแอปบนมือถือ:** การ์ด “ติดตั้งแอป เข้าแถว” อยู่ใต้ฟอร์มเข้าสู่ระบบ ท้ายหน้าแรก และในเมนู ☰ เพิ่มเติม
  - Android (Chrome): กดปุ่ม 📲 ติดตั้งแอป หรือเมนู ⋮ → “ติดตั้งแอป” / “เพิ่มลงในหน้าจอหลัก”
  - iPhone (Safari): ปุ่มแชร์ ⬆ → “เพิ่มไปยังหน้าจอโฮม” → “เพิ่ม”
  - เปิดลิงก์จาก LINE/Facebook ติดตั้งไม่ได้ ต้องเลือก “เปิดในเบราว์เซอร์” ก่อน
  - หลังถอนการติดตั้ง Chrome อาจยังไม่แสดงปุ่มสักระยะ ใช้เมนู ⋮ แทนได้
- ถ้าขึ้น “หน้าเว็บในเครื่องนี้เป็นเวอร์ชันเก่า” หรือหน้าตาไม่ตรงคู่มือ: ปิดแอปแล้วเปิดใหม่ (บางเครื่อง 2 ครั้ง) หรือกด Ctrl+F5 บนคอมพิวเตอร์ แอปอัปเดตตัวเองอัตโนมัติ

## การเช็กชื่อเข้าแถว (หน้าแรก)
- เช็กได้เฉพาะวันเข้าแถวและในช่วงเวลาที่ผู้ดูแลตั้ง (ปกติ จันทร์–ศุกร์ 07:30–08:30 น.) หน้าแรกบอกเวลาปัจจุบันและสถานะ “เปิดเช็กชื่อ / ปิดแล้ว / งดกิจกรรม”
- **วิธีหลัก GPS:** แตะปุ่มวงกลม “แตะเพื่อเช็กชื่อเข้าแถว” อนุญาตตำแหน่ง ต้องอยู่ในพื้นที่ลานเข้าแถว ระบบบอกระยะห่างและความแม่นยำ
  - GPS ไม่แม่นหรืออยู่นอกพื้นที่: ออกไปที่โล่ง รอสักครู่แล้วลองใหม่ เปิดโหมดตำแหน่งความแม่นยำสูง
- **สแกน QR:** ปุ่ม “สแกน QR” ใช้กล้องสแกน QR ที่งานกิจกรรมแสดงที่ลาน (QR เปลี่ยนทุกไม่กี่วินาที ถ่ายรูปส่งต่อใช้ไม่ได้)
- **ส่งคำขอให้ตรวจสอบ:** เมื่อเช็กไม่ผ่าน (เช่น GPS เพี้ยน) กดส่งคำขอพร้อมหมายเหตุ สถานะเป็น “รอตรวจสอบ” จนงานกิจกรรมอนุมัติ
- **แนบรูปหลักฐาน** (ไม่บังคับ) ได้สูงสุด 3 รูปตอนเช็กชื่อ
- **โหมดกดปุ่ม:** ถ้าผู้ดูแลตั้งโหมดนี้ กดปุ่มเดียวก็เช็กได้ไม่ต้องใช้ GPS
- ถ้ามีคนเช็กแทน กล่องผลวันนี้จะแสดง “เช็กแทนโดย …” และเวลา
- ห้ามให้ผู้อื่นใช้บัญชีของตน ระบบตรวจจับอุปกรณ์เดียวกันเช็กหลายบัญชีและติดธงให้ตรวจ
- วันที่ไม่มีบันทึกหลังปิดระบบจะนับเป็น “ขาด” ในรายงาน
- **มือถือเสีย / เช็กเองไม่ได้:** ให้ตัวแทนหรือเพื่อนในแผนกเช็กแทนในช่วงเปิดระบบ หรือแจ้งงานบุคลากรบันทึก “มา (เช็กชื่อแทน)” ย้อนหลังได้

## เช็กแทน (ตัวแทนเช็กชื่อแผนก / หัวหน้าแผนก)
- เมนู 👥 รายชื่อ หรือการ์ด “เช็กชื่อให้เพื่อน” หน้าแรก → แตะชื่อ → เลือกสถานะ → บันทึก
- เช็กแบบกลุ่ม: เลือกหลายคน → แนบรูปรวมที่ลาน → บันทึกพร้อมกัน
- โหมด “เช็กแทนกันในแผนก” (ผู้ดูแลเปิด) ทุกคนในแผนกเช็กให้กันได้ และอาจบังคับแนบรูป
- ทุกการเช็กแทนบันทึกชื่อผู้เช็ก เจ้าตัวเห็นในประวัติ
- รายงานแผนก: ร้อยละเข้าแถวรายคน/รายวัน ส่งออก Excel, CSV, พิมพ์ PDF

## ประวัติและสถิติของฉัน (เมนู 🗓 ประวัติ)
- ตัวเลขสรุป 4 ช่อง: มาเข้าแถว / ราชการหรืองานนโยบาย / ลา / รอตรวจสอบ
- แท็บ 📋 รายการ: 60 วันล่าสุดพร้อมวิธีเช็ก เวลา ผู้บันทึกแทน
- แท็บ 📅 ปฏิทิน: สีตามสถานะ เขียว=มา ฟ้า=ราชการ/นโยบาย เทา=ลา แดง=ขาด ส้ม=รอตรวจ แตะวันเพื่อดูรายละเอียด
- แท็บ 📊 รายเดือน: ร้อยละทั้งช่วง เดือนนี้ เทียบเดือนก่อน กราฟแท่งเส้นเกณฑ์ 80% และตาราง
- แท็บ ⏰ เวลาเช็กชื่อ: เวลาเฉลี่ย เร็วสุด ช้าสุด กราฟช่วงเวลา 10 นาที ความต่อเนื่อง วิธีเช็ก
- เลือกช่วงได้: ภาคเรียนนี้ / ปีการศึกษา / 3 เดือนล่าสุด
- ร้อยละ = วันที่มา ÷ วันเข้าแถวที่ปิดระบบแล้ว (ราชการ งานนโยบาย ลา แสดงแยก ไม่นับเป็นมา) วันหยุด/งดกิจกรรม/วันนี้ก่อนปิดระบบ ไม่นับขาด
- ถ้าวันที่ขึ้นขาดทั้งที่มาจริงหรือลา/ไปราชการ ให้แจ้งงานบุคลากรหรือหัวหน้าแผนกแก้ไข

## โปรไฟล์และลายเซ็น
- แตะชื่อมุมขวาบน หรือ ☰ → การ์ดชื่อ: เปลี่ยนรูป แก้ตำแหน่ง/วิทยฐานะ เบอร์โทร เปลี่ยนอีเมล (ยืนยันรหัสผ่าน) เปลี่ยนรหัสผ่าน
- ชื่อ-สกุลและแผนก แก้โดยผู้ดูแลระบบเท่านั้น
- **ลายเซ็น** (สำหรับผู้ลงนาม): เซ็นด้วยนิ้ว/เมาส์ในกรอบ หรือ “อัปโหลดรูปลายเซ็น” (JPG/PNG) ระบบลบพื้นกระดาษให้โปร่งใสและย่อขนาดอัตโนมัติ → “บันทึกลายเซ็น” → ยืนยันรหัสผ่าน
  - ไฟล์ HEIC จาก iPhone บางเครื่องเปิดไม่ได้ ให้แคปหน้าจอรูปลายเซ็นแล้วอัปโหลด
- สำรองข้อมูลงานของฉัน: ☰ → 📦 สำรองข้อมูลงานของฉัน ดาวน์โหลด Excel ตามหน้าที่ (ยืนยันรหัสผ่าน)

## งานกิจกรรม
- แสดง QR ที่ลาน: ☰ → แสดง QR (เปิดค้างบนจอ/แท็บเล็ต)
- ตรวจคำขอ: แท็บ “รอตรวจสอบ” อนุมัติ/ไม่อนุมัติ ดูรูปและระยะ รายการ ⚠ ติดธง ตรวจเรื่องอุปกรณ์ซ้ำ
- บันทึกไปราชการ/ลาแทน และแก้ไขย้อนหลังได้ ทุกการแก้มีประวัติ
- ปฏิทิน: ตั้งวันหยุด วันงดกิจกรรม วันเข้าแถวพิเศษ ภาคเรียน (ชื่อเช่น 2/2569) และนำเข้าวันหยุดนักขัตฤกษ์
- เปิด/ปิดการเช็กชื่อของวันนี้ก่อนเวลาได้จากกล่อง “วันนี้” หน้าแรก

## งานบุคลากรประจำวัน (เจ้าหน้าที่บุคลากร / ผู้ดูแล)
- ☰ → 🗂 งานบุคลากรประจำวัน เลือกวันที่ด้านบน
- แท็บ “ลา / ราชการ / นโยบาย”: แตะชื่อ (หลายคนได้) → ตั้งสถานะ → เลือก ไปราชการ / งานนโยบาย / ลาป่วย / ลากิจ / ลาอื่น ๆ / มา (เช็กชื่อแทน) / ล้างสถานะ → ตั้งแต่–ถึง (ข้ามวันหยุดให้ สูงสุด 31 วัน) → บันทึก
  - ไปราชการ / งานนโยบาย **ต้องกรอกรายละเอียด** (สถานที่ / เลขที่คำสั่ง) ช่องจะเป็นกรอบส้มและปุ่มขึ้น “กรอกรายละเอียดก่อนบันทึก”
  - “มา (เช็กชื่อแทน)” ใช้เมื่อครูมือถือเสียหรือแก้คนที่บันทึกผิดว่าลา บันทึกล่วงหน้าไม่ได้ ใส่เหตุผล เช่น “มือถือเสีย”
- แท็บ “มาสาย / ไม่ลงเวลากลับ”: แตะเลือกคนตามข้อมูลเครื่องลงเวลา แล้วกดบันทึก
- แท็บ “ประเภทบุคลากร”: กำหนดประเภท (ข้าราชการครู ครูผู้ช่วย พนักงานราชการ ลูกจ้างชั่วคราว ฯลฯ) ใช้นับในข้อ 1 ของรายงาน
- **รายงานสรุปการปฏิบัติงานของข้าราชการครู และบุคลากรทางการศึกษา (ประจำวัน)**
  - สร้างได้หลังปิดเวลาเช็กชื่อ วันละ 1 ฉบับ: ท้ายหน้างานบุคลากร “ตรวจตัวเลขก่อนสร้าง” → “สร้างและส่งลงนาม” หรือจากเมนู เอกสารเสนอลงนาม
  - ข้อ 1 จำนวนบุคลากรตามประเภท · 2 ไปราชการ · 3 ลา · 4 งานนโยบาย · 5 ผู้ไม่เข้ากิจกรรมหน้าเสาธง · 6 มาลงเวลาเกินกำหนด · 7 ไม่ลงเวลากลับ · ผู้มา/ไม่มาปฏิบัติงาน
  - ลงนาม 3 ลำดับ: ผู้รายงาน (หัวหน้างานบริหารและพัฒนาทรัพยากรบุคคล) → ผู้ตรวจสอบ (รองผู้อำนวยการฝ่ายบริหารทรัพยากร) → ผู้อำนวยการ (เลือก ☐ ทราบ ☐ มอบ/…)
  - รูปแบบหนังสือราชการ ไม่มีกรอบ ฟอนต์ TH Sarabun 16 พอยต์ พิมพ์ A4
- **เอกสารถูกส่งกลับแก้ไข:** หน้าแรกมีแถบแดง เมนูมีตัวเลข หน้ารายการเปิดแท็บ “ส่งกลับ” พร้อมเหตุผล
  - วิธีแก้: เปิดเอกสาร → ✏️ แก้ไขเอกสาร ↓ → ① แก้ข้อมูลในรายงาน (เปิดหน้างานบุคลากรตรงวันนั้น) → แก้สถานะ → 💾 บันทึกการแก้ไขและส่งลงนามใหม่ → เอกสารฉบับเดิมกลับไปรอลำดับ 1
  - เปลี่ยน ② วันที่ และ ③ ชื่อเอกสาร ได้ในกล่องจัดการเอกสาร
- **สิทธิ์แก้ไข/ลบเอกสาร:** เจ้าหน้าที่บุคลากรทุกคนจัดการแทนกันได้
  - ยังไม่มีใครลงนาม: แก้ไขได้ ลบได้ · มีผู้ลงนามแล้ว: แก้ไขไม่ได้ (🔒 ให้ผู้ลงนามกด “ส่งกลับแก้ไข”) ลบได้ · ถูกส่งกลับ: แก้ไขได้ ลบได้ · อนุมัติแล้ว: ลบได้เฉพาะผู้ดูแลระบบ
  - ลบต้องยืนยันรหัสผ่าน

## ผู้บริหารและผู้ลงนาม
- เมื่อถึงลำดับ: หน้าแรกมีแถบ “มีเอกสารรอท่านลงนาม” และอีเมลแจ้ง (ถ้าตั้งค่าอีเมลแล้ว)
- ☰ → 📝 เอกสารเสนอลงนาม → แท็บ “รอท่านลงนาม” → แตะเอกสารหรือปุ่ม “ลงนาม ›”
- ลงนาม: ใช้ลายเซ็นที่บันทึกในโปรไฟล์ หรือเซ็นในกรอบ → ✍ ลงนาม → ยืนยันรหัสผ่าน ผู้อำนวยการเลือก ทราบ/มอบ ก่อน
- ส่งกลับแก้ไข: พิมพ์เหตุผลในช่องความเห็น → ส่งกลับแก้ไข → ยืนยันรหัสผ่าน
- ไม่สะดวกลงนามในระบบ: ให้เจ้าหน้าที่กด “🖊 พิมพ์ลงนามด้วยมือ” แล้วเสนอแฟ้มตามปกติ
- รายงานผู้บริหาร: ภาพรวมรายสัปดาห์/รายเดือนของ 16 หน่วยงาน ส่งออก Excel/PDF

## ผู้ดูแลระบบ
- ตั้งค่า: เวลาเปิด–ปิด วันเข้าแถว พื้นที่ลาน (แผนที่ รัศมี) วิธีเช็กชื่อ (GPS/QR/กดปุ่ม/ไม่ตรวจ) เช็กแทนกันในแผนก
- ผู้ใช้: เพิ่ม/แก้/ระงับ รีเซ็ตรหัสผ่าน กำหนดบทบาท ตัวแทนแผนก ผู้ไม่ต้องเข้าแถว
- นำเข้า/ส่งออกผู้ใช้ด้วย Excel (ดาวน์โหลดแม่แบบ → กรอก → ตรวจก่อนบันทึก) และ API เชื่อมระบบภายนอกด้วยกุญแจ API
- แบบรายงาน: ผู้ลงนาม 3 ลำดับ หน่วยงาน 16 หน่วย
- ข้อมูลจำลอง: สร้าง/ลบข้อมูลฝึกใช้งาน (ป้าย “จำลอง”)
- สำรองและกู้คืนระบบ: สำรองอัตโนมัติทุกวัน “สำรองตอนนี้” ดาวน์โหลดไฟล์กู้คืนทั้งระบบ (.tar) และกู้คืนเมื่อเซิร์ฟเวอร์มีปัญหา (พิมพ์ยืนยัน)
- อีเมลรีเซ็ตรหัสผ่าน: ตั้งค่า SMTP ในไฟล์ .env บนเซิร์ฟเวอร์ (Gmail + App password) ดูคู่มือผู้ดูแลหัวข้อ 9
- ลิงก์สาธิตการติดตั้งแอป: /login?install=demo (ปิดด้วย ?install=off)

## สถานะการเข้าแถว
| สถานะ | ความหมาย |
| --- | --- |
| มาเข้าแถว | เช็กชื่อสำเร็จ |
| ขาด | ไม่มีบันทึกเมื่อปิดระบบ |
| ไปราชการ | ไปตามคำสั่ง (งานกิจกรรม/บุคลากรบันทึก) |
| ติดงานนโยบาย | ปฏิบัติงานตามนโยบาย |
| ลา (ลาป่วย/ลากิจ/ลาอื่น ๆ) | ตามใบลา งานบุคลากรบันทึก |
| รอตรวจสอบ | ส่งคำขอแล้ว รองานกิจกรรมอนุมัติ |

## ติดต่อ
- สถานะการเช็กชื่อ คำขอ QR ปฏิทิน: งานกิจกรรม
- ลา ไปราชการ มาสาย รายงานประจำวัน: งานบุคลากร
- บัญชี รหัสผ่าน สิทธิ์ ตั้งค่าระบบ: ผู้ดูแลระบบ
- ผู้พัฒนาระบบ: ครูอลงกรณ์ ภูคงคา ครูกฤษณา แนววิเศษ และทีมงาน แผนกวิชาเทคโนโลยีสารสนเทศ
