# ระบบเช็กชื่อเข้าแถวบุคลากร — วิทยาลัยเทคนิคชัยภูมิ

เว็บแอปที่ออกแบบให้ใช้บนมือถือก่อน (PWA ติดตั้งลงหน้าจอหลักได้) สำหรับเช็กชื่อเข้าแถวช่วง 07:30–08:30 น.
URL ใช้งานจริง: **https://lineup.ccollege.ac.th**

**ติดตั้ง:** ดู [INSTALL.md](INSTALL.md) · **ทดสอบ:** ดู [TESTING.md](TESTING.md) · **คู่มือผู้ใช้แยกตามบทบาท:** [docs/](docs/)

> ไฟล์รายชื่อบุคลากร (`backend/data/personnel.json`), รหัสผ่าน และไฟล์ `.env` เป็นข้อมูลส่วนบุคคล/ความลับ **ไม่ได้อยู่ใน repository นี้** ดูวิธีเตรียมใน INSTALL.md

**ผู้พัฒนา:** ครูอลงกรณ์ ภูคงคา และครูกฤษณา แนววิเศษ แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคชัยภูมิ

## ความสามารถเพิ่มเติม (รุ่น 2)

- ลืมรหัสผ่าน → ลิงก์รีเซ็ตทางอีเมล 30 นาที ใช้ครั้งเดียว (ต้องตั้ง SMTP_* ใน deploy/.env)
- ข้อมูลจำลองสำหรับฝึก/ดูรายงาน + ลบข้อมูลจำลอง + ล้างข้อมูลทั้งหมดเพื่อเริ่มใช้จริง (ผู้ดูแล ยืนยันรหัสผ่าน)
- ตั้งพื้นที่เข้าแถวบนแผนที่ (ปักหมุดกลางจอ ภาพดาวเทียม ค้นหาสถานที่ ตำแหน่งปัจจุบัน)
- ผู้ดูแลติ๊กตัวแทนเช็กชื่อแผนกได้ในหน้าผู้ใช้ หรือเปิดโหมด "เช็กแทนกันได้ทั้งแผนก" พร้อมเช็กแบบกลุ่มด้วยรูปถ่ายรวม
- แนบรูปหลักฐานได้สูงสุด 3 รูปทุกกรณี (เช็กเอง คำขอตรวจสอบ เช็กแทน บันทึกโดยงานกิจกรรม)
- สำรองฐานข้อมูลอัตโนมัติ 00:00 น. หลังวันทำการ (container backup) + ปุ่มสำรอง/ดาวน์โหลดในหน้าผู้ดูแล
- แบบบันทึกการเข้าร่วมกิจกรรมหน้าเสาธงตามแบบฟอร์มวิทยาลัย + ลำดับลงนาม 3 ขั้น (ผู้รับรอง → ผู้รับรอง → ผู้อำนวยการอนุมัติ) พิมพ์ A4
- รายงานผู้บริหาร 4 รูปแบบ: สรุปหน้าเดียว แนวโน้มรายวัน เปรียบเทียบหน่วยงาน ตารางสี
- โปรไฟล์: รูป ตำแหน่ง เบอร์โทร อีเมล ลายเซ็น

## กติกาที่ระบบใช้ (ตั้งค่าได้ที่หน้า "ตั้งค่าระบบ")

- **เวลา**: เปิด 07:30:00 ถึง 08:30:59 (นับนาทีที่ 08:30 ว่าทัน) ใช้เวลาเซิร์ฟเวอร์ เขตเวลาไทย
- **วันเข้าแถว**: จันทร์–ศุกร์ ประกาศงด/วันหยุดได้ที่ "ปฏิทินวันเข้าแถว" วันที่งดจะไม่นับในรายงาน
- **วิธีเช็กชื่อ** (ค่าเริ่มต้น `gps_or_qr`)
  - อยู่ในพื้นที่ (GPS ผ่าน) → มาเข้าแถว
  - GPS ไม่ชัด/ไม่ได้รับอนุญาต → สแกน QR ที่จุดเข้าแถวด้วยกล้องมือถือ → มาเข้าแถว
  - นอกพื้นที่ → ส่ง "คำขอตรวจสอบ" (แนบหมายเหตุ/รูปได้) ให้งานกิจกรรมอนุมัติ
  - QR ถูกต้องแต่ GPS อยู่นอกพื้นที่ชัดเจน → รอตรวจสอบ (กันการส่งรูป QR ให้คนอื่น)
- **QR หมุนเวียน** เปลี่ยนทุก 30 วินาที (ลงลายมือชื่อ HMAC) ใช้ได้ไม่เกิน 2 นาที
- **กันเช็กชื่อแทนกัน**: อุปกรณ์เดียวกันเช็กให้หลายบัญชีในวันเดียว → ติดธง ⚠ ทุกรายการ
- **ขาด**: ไม่ต้องกดบันทึก ใครไม่มีบันทึกเมื่อปิดระบบ นับเป็น "ขาด" อัตโนมัติ
- **อัตราเข้าแถว** = มาเข้าแถว ÷ (ครั้งที่ต้องเข้าแถว − ไปราชการ − ติดงานนโยบาย − ลา)
- ทุกการบันทึก/แก้ไขเก็บใน `attendance_events` (ไม่ลบ ไม่แก้) ระบุผู้ทำ เวลา เหตุผล IP

## สิทธิ์ผู้ใช้

| บทบาท | ทำได้ |
|---|---|
| บุคลากร | เช็กชื่อเอง ดูประวัติตัวเอง |
| + ผู้รับมอบหมายเช็กแทน (`can_proxy`) | เช็ก "มาเข้าแถว" แทนคนในแผนกเดียวกัน **เฉพาะช่วงเปิด** ดูรายชื่อ/รายงานแผนก |
| หัวหน้าแผนก | ดูรายชื่อและรายงานแผนกตัวเอง |
| เจ้าหน้าที่งานกิจกรรม | บันทึกทุกสถานะให้ทุกคน (ต้องมีเหตุผล) แก้ย้อนหลัง อนุมัติคำขอ แสดง QR จัดปฏิทิน/ภาคเรียน ดูรายงานทั้งหมด |
| ผู้บริหาร | ดูรายงานทั้งหมด |
| ผู้ดูแลระบบ | ทุกอย่าง + จัดการผู้ใช้ สิทธิ์ รีเซ็ตรหัสผ่าน ตั้งค่าระบบ |

ค่าเริ่มต้นหลังนำเข้า: ทุกคนเป็น "บุคลากร", ผู้ที่อยู่ "งานกิจกรรมนักเรียน นักศึกษา" เป็น "เจ้าหน้าที่งานกิจกรรม",
และมีบัญชี `admin` — **ผู้ดูแลต้องกำหนดหัวหน้าแผนก ผู้บริหาร และผู้รับมอบหมายเช็กแทนเองที่หน้า "ผู้ใช้และสิทธิ์"**

## ข้อมูลบุคลากร

นำเข้าจาก `รายชื่อครู ระบบสารบรรณอิเล็กทรอนิกส์ (GDCC e-Offi.xlsx` → `backend/data/personnel.json`
(179 คน, 36 แผนก/งาน) ด้วย `node scripts/import-excel.js` ชื่อผู้ใช้ = **รหัสพนักงาน** หรืออีเมล รหัสผ่านเริ่มต้น `12345678`
ต้องเปลี่ยนรหัสและยอมรับเงื่อนไข PDPA ตอนเข้าครั้งแรก

อัปเดตรายชื่อภายหลัง: แปลง Excel ใหม่เป็น `personnel.json` แล้วรัน
`docker compose exec app node scripts/seed.js --out /app/uploads/new.csv` (คนเดิมไม่ถูกรีเซ็ตรหัส)


`SANDBOX_TIME=2026-11-09T07:45:00+07:00` ใน `backend/.env` ทำให้ระบบจำลองเวลา (สำหรับฝึก/UAT) — ใช้ไม่ได้เมื่อ `NODE_ENV=production`

## ติดตั้งบนเซิร์ฟเวอร์ (Ubuntu 24.04)

1. DNS: ให้ระเบียน A `lineup.ccollege.ac.th` → `203.113.123.204` และเปิดพอร์ต 80/443 จากอินเทอร์เน็ต
2. คัดลอกโปรเจกต์ไปที่ `/opt/lineup` แล้วรัน

```bash
sudo bash /opt/lineup/deploy/install.sh lineup.ccollege.ac.th ผู้ดูแล@ccollege.ac.th
```

สคริปต์จะ: ติดตั้ง Docker, ตั้ง firewall, สุ่มรหัสผ่าน/secret ลง `deploy/.env`, build และเริ่มระบบ,
นำเข้าบุคลากร (รหัสผ่านเริ่มต้นอยู่ที่ `deploy/initial-passwords.csv` — แจกแล้วลบ), ขอ HTTPS,
ตั้ง cron ต่ออายุใบรับรอง; การสำรองฐานข้อมูลทำโดย container `backup` (00:00 น. อ.–ส., `deploy/backups/`, เก็บ 60 วัน)

อัปเดตเวอร์ชัน: `cd /opt/lineup/deploy && docker compose up -d --build`

## หลังติดตั้ง — สิ่งที่ผู้ดูแลต้องทำก่อนใช้จริง

1. เข้าด้วย `admin` → เปลี่ยนรหัสผ่าน
2. **ตั้งค่าระบบ → พื้นที่เข้าแถว**: ยืนกลางลานเข้าแถว กด "ใช้ตำแหน่งปัจจุบัน" ตั้งรัศมี (เริ่ม 150 ม.)
3. ผู้ใช้และสิทธิ์: กำหนดหัวหน้าแผนก ผู้บริหาร ผู้รับมอบหมายเช็กแทน และติ๊ก "ไม่ต้องเข้าแถว" ให้ผู้ที่ได้รับยกเว้น
4. ปฏิทิน: เพิ่มภาคเรียน และวันหยุด
5. ทดลองใช้ควบคู่วิธีเดิม (Pilot) ตามแผน UAT ก่อนใช้เป็นหลักฐานจริง
