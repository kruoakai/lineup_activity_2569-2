3. เช็กแทนรายคน

ใช้เมื่อมีเพียงไม่กี่คนที่เช็กเองไม่ได้ เช่น มือถือแบตหมด

  1. เมนู 👥 รายชื่อ → แท็บ ยังไม่เช็ก
  2. เห็นตัวเพื่อนครูที่จุดเข้าแถวก่อน
  3. แตะปุ่มท้ายชื่อ:
    • มา ✓ บันทึกทันที (ตัวแทนที่ผู้ดูแลติ๊กไว้)
    • 📷 มา เปิดกล่องแนบรูป (โหมดเช็กแทนกันทั้งแผนกที่ต้องแนบรูป)
  4. ถ้าต้องแนบรูป: แตะ 📷 เพิ่มรูป → ถ่ายรูปเพื่อนครูที่จุดเข้าแถว (สูงสุด 3 รูป)
  5. แตะ บันทึก "มาเข้าแถว" แทน

ถ้ากดบันทึกโดยยังไม่แนบรูป จะขึ้นข้อความสีแดง "⚠ ยังไม่ได้แนบรูป" และระบบจะยังไม่บันทึก ให้แนบรูปแล้วกดอีกครั้ง ตัวท่านเองไม่มีปุ่มเช็กแทน ให้เช็กชื่อตัวเองที่หน้า ✓ เช็กชื่อ

4. เช็กชื่อแบบกลุ่มด้วยรูปถ่ายรวม

เร็วที่สุดเมื่อคนในแผนกยืนรวมกัน ถ่ายรูปเดียวแล้วบันทึกทั้งแผนก

  1. เมนู 👥 รายชื่อ → แตะ 📸 เช็กชื่อแบบกลุ่ม (ถ่ายรูปรวม) · ยังไม่เช็ก X คน
  2. แตะ 📷 เพิ่มรูป → ถ่ายรูปรวมทุกคนที่มาเข้าแถว (1–3 รูป ถ้าคนเยอะถ่ายหลายมุมได้)
  3. ระบบติ๊กเลือก ทุกคนที่ยังไม่เช็ก ไว้ให้ → แตะเอาชื่อคนที่ไม่มาออก (ป้ายจะเปลี่ยนเป็น "ไม่มา") มีปุ่ม เลือกทั้งหมด และ ไม่เลือกเลย ช่วย
  4. ตรวจตัวเลข "เลือก X / Y คน" ให้ตรงกับคนในรูป
  5. แตะ ✓ บันทึก "มาเข้าแถว" X คน

ผลการบันทึกขึ้นด้านบนหน้า เช่น "บันทึก 'มาเข้าแถว' 9 คน พร้อมรูปรวม" ถ้ามีคนถูกข้าม ระบบจะบอกชื่อและเหตุผลทีละคน เช่น เช็กเองไปแล้วระหว่างที่ท่านกำลังถ่ายรูป

  • ทุกคนที่เลือกได้รูปรวมชุดเดียวกัน และบันทึกชื่อท่านเป็นผู้เช็กแทน
  • คนที่ไม่ได้เลือกจะยังไม่ถูกบันทึก เช็กเองได้จนปิดเวลา ถ้าไม่เช็กจะเป็น "ขาด"
  • กดบันทึกโดยไม่แนบรูปจะขึ้นข้อความเตือนสีแดง ระบบยังไม่บันทึก
  • กด ปิด ได้ตลอดก่อนกดบันทึก ไม่มีอะไรถูกบันทึก

6. รายงานแผนก (📊 รายงาน)

หัวหน้าแผนกและตัวแทนที่ผู้ดูแลติ๊กไว้ เห็นรายงานเฉพาะแผนกตัวเอง ตัวเลขคำนวณจากข้อมูลจริงทันที (โหมดเช็กแทนกันทั้งแผนกไม่ได้สิทธิ์ดูรายงาน)

  1. เลือกช่วง: รายวัน · รายสัปดาห์ · รายเดือน · ภาคเรียน · กำหนดเอง แล้วเลื่อนด้วยปุ่ม ‹ ›
  2. ดูตัวเลขสรุปด้านบน: อัตราเข้าแถว มา ขาด ราชการ/งานนโยบาย ลา รอตรวจสอบ ยังไม่เช็ก และถูกบันทึกแทน
  3. ดูกราฟสัดส่วนสถานะ และแนวโน้มรายวัน (เมื่อเลือกมากกว่า 1 วัน)
  4. ตาราง รายบุคคล เรียงตามชื่อ อัตราเข้าแถวน้อย→มาก หรือจำนวนขาด

ไม่มีเมนู 👥 รายชื่อ

ยังไม่ได้รับสิทธิ์ แจ้งผู้ดูแลระบบ หรือออกจากระบบแล้วเข้าใหม่หลังผู้ดูแลให้สิทธิ์
